# 🗄️ SKILL: Database Schema, SQL Optimization & ORM

## Relational & NoSQL Stack
- Databases: PostgreSQL, MySQL, SQLite, Redis, MongoDB.
- ORMs: Drizzle ORM (type-safe SQL builder), Prisma (schema modeling), Kysely.

## Advanced SQL & Performance
- Indexing: B-Tree for equality/range, GIN for JSONB and Full-Text Search, BRIN for time-series data.
- Advanced Queries: Window functions (`ROW_NUMBER()`, `RANK()`), Common Table Expressions (`WITH`), Subqueries.
- Redis Caching: Cache-Aside pattern, Rate Limiting storage, Session store with TTL invalidation.
- Migrations: Zero-downtime Expand-Contract pattern for database schema updates.
