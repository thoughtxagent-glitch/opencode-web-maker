# 🎨 SKILL: UI/UX & Anti-Generic Design Systems

## Core Philosophy
1. Zero AI-Slop: Banned default purple/indigo gradients, un-tweaked Inter font polosan, and standard 3-card hero layouts.
2. Surface Archetype System: Monitor / Operate / Compare / Decide — determine the surface goal before writing CSS.
3. OKLCH Color Space: Use OKLCH for perceptual uniformity, high saturation control, and 100% WCAG AAA accessibility contrast.
4. Glassmorphism 2.0 & Dark Neobrutalism: Multi-layered backdrop blurs (`backdrop-blur-md` to `xl`), hairline subtle borders (`border-white/10`), inset glow, crisp shadows, and tactical micro-badges.
5. Bento Grid 2.0: Modular, variable aspect ratio layouts inspired by Vercel, Linear, Apple, and Notion.

## Design Systems Supported (54 Ready Systems Synthesis)
- Stripe: Clean, financial clarity, subtle gradients, high precision typography.
- Linear: Ultra-sleek dark mode, keyboard shortcuts hints, high-contrast crisp borders.
- Vercel: High-contrast monochromatic black/white, geometric clarity, subtle animated grid lines.
- Notion: Clean typography, warm neutral surfaces, organic borders.
- Apple: Glassmorphism, smooth spring curves, spatial depth, focus ring indicators.

## Typography Guidelines
- Pairing: Geist Sans + Geist Mono, JetBrains Mono + Inter (tweaked tracking), Plus Jakarta Sans + Fira Code.
- Scale: Strict modular scale (`text-xs` to `text-7xl`) with explicit `tracking-tight` on headings and `leading-relaxed` on body text.
