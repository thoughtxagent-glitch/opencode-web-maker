# 🚀 SKILL: DevOps, Testing & Core Web Vitals Optimization

## Core Web Vitals Standards
- LCP (Largest Contentful Paint): `< 1.2s`.
- CLS (Cumulative Layout Shift): `0.00`.
- INP (Interaction to Next Paint): `< 50ms`.

## Automated Testing & CI/CD
- Unit & Component Testing: Vitest / Jest + React Testing Library (RTL) + MSW (Mock Service Worker).
- E2E Testing: Playwright cross-browser testing scripts.
- Load Testing: k6 virtual user simulation scripts.

## Containerization
- Docker: Multi-stage Dockerfile producing ultra-small production images (~50MB).
- Docker Compose: Orchestration for App + PostgreSQL + Redis + Nginx Reverse Proxy.
