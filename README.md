# 🚀 OpenCode Web.Maker Custom Agent

Custom Agent **`web.maker`** untuk OpenCode dengan mode **`web`** (primary agent di samping `build` dan `plan`).

## 🌟 Fitur Utama
- **3 Primary Agents (Tab Navigation)**: `build`, `plan`, dan **`web`**.
- **Super Complete Web Skills Arsenal**:
  - 🎨 **Anti-Generic UI/UX Design System**: Bento Grids, Glassmorphism 2.0, Dark Neobrutalism, OKLCH Color Space, WCAG AAA.
  - ⚛️ **Modern Frontend**: Next.js 14/15, React 19, Vue/Nuxt 3, SvelteKit, Tailwind CSS v4, Framer Motion, p5.js/WebGL.
  - ⚡ **High-Performance Backend**: Node.js, Express, Fastify, Bun, NestJS, FastAPI, Go, GraphQL, tRPC, WebSockets/SSE.
  - 🗄️ **Database & ORM**: PostgreSQL, MySQL, SQLite, Redis, Prisma, Drizzle ORM, Supabase.
  - 🛡️ **Security Hardening (OWASP Top 10)**: Zod validation, JWT RS256, HttpOnly cookies, Helmet, Rate limiting.
  - 🚀 **DevOps & Performance**: Docker, Nginx, Vercel, Cloudflare, Core Web Vitals (LCP, CLS, INP), Playwright/Jest testing.

## 🛠️ Cara Instasi ke Global OpenCode
Copy file `web.md` ke folder agent global OpenCode kamu:

```bash
mkdir -p ~/.config/opencode/agent
cp .opencode/agent/web.md ~/.config/opencode/agent/web.md
```

Setelah disetup, jalankan `opencode` dan kamu bisa menekan **Tab** untuk berpindah antar mode: `build` ➔ `plan` ➔ **`web`** 🔥
